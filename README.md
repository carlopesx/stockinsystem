# Sistema de Gerenciamento de Estoque

Este é um projeto de estudo desenvolvido em Python com o objetivo de criar um sistema de gerenciamento de estoque.

Atualmente, o projeto conta com a estrutura inicial do menu de navegação, permitindo o acesso às funcionalidades principais do sistema. O desenvolvimento está em andamento e novas funcionalidades, melhorias de código e aprimoramentos na interface serão adicionados gradualmente.

## Funcionalidades planejadas

* Cadastro de produtos
* Edição de produtos
* Visualização de estoque
* Controle de entradas e saídas
* Interface gráfica
* Persistência de dados
* Relatórios e consultas
